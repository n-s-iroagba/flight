# Investment Company Feature List

# 

| Feature ID | Feature Name | Description | Actor(s) |
| :---- | :---- | :---- | :---- |
| EDU-01 | Admin Course/Lesson Management | Admin can create and manage courses and lessons. | Admin |
| EDU-02 | Quiz Management | Admin can create and manage quizzes per lesson. | Admin |
| EDU-03 | Certification | System automatically generates certificates upon course completion. | System |
| INV-01 | Wallet Funding | Clients can fund their wallets via earnest invoice. | Client |
| INV-02 | Admin Wallet Management | Admin can manually update client wallet balances. | Admin |
| INV-03 | Trading (UAE Stocks & Bonds) | Users can trade UAE stocks and bonds (sourced via TwelveData) with backend execution. | User |
| INV-04 | Automated Returns | System adds a 1% daily return to stocks and bonds trades. | System |
| INV-05 | REITS Trading | Users can trade REITS (managed by admin). | User, Admin |
| NTH-01 | Transaction History | System tracks and displays user transaction history. | System, User |
| NTH-02 | Course Progress Tracking | System tracks and displays student progress through courses. | System, User |
| NTH-03 | Notifications | System provides notifications for various activities. | System |
| USR-01 | KYC/Onboarding | Clients must complete identity verification before funding or trading. | Client, Admin |
| INV-06 | Balance Validation | System validates available wallet balance before executing any trade orders. | System |
| INV-07 | Trade Confirmation/Receipt | System generates a digital receipt and confirmation for every successful trade. | System, User |

| INV-08 | Withdrawal Request Flow | Clients can request to withdraw funds, subject to admin approval and processing. | Client, Admin |
| :---- | :---- | :---- | :---- |
